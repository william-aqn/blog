# AmneziaWG-сервер на ASUS роутере

![logo](/assets/blog/amneziawg/logo.png)

В [прошлом посте]({% post_url 2026-06-18-asus-amneziawg %}) роутер ходил **наружу** через AmneziaWG. Теперь аддон [asuswrt-merlin-amneziawg](https://github.com/william-aqn/asuswrt-merlin-amneziawg) умеет и обратное - принимать **входящие** подключения: телефон или ноутбук из любой точки мира подключается к дому и получает домашнюю сеть (NAS, камеры, RDP) плюс интернет через домашний IP.

## Настройка за минуту

Ставится/обновляется как обычно:

```sh
curl -sfL https://raw.githubusercontent.com/william-aqn/asuswrt-merlin-amneziawg/main/install-online.sh | sh
```

Дальше в админке появляется вторая страница - **VPN > AmneziaWG Server**:

1. **Сгенерировать** - ключи сервера (создаются прямо в браузере, приватники никуда не отправляются)
2. **+ Добавить пира** - имя и IP выдаются сами
3. **Применить** → **Запустить сервер**
4. Жмём **QR** у пира и сканируем приложением [AmneziaWG](https://amnezia.org) (2.x) - всё, телефон дома

![server-ui](/assets/blog/amneziawg/screenshot_server.png)

QR-код тоже рисуется в браузере роутера - без внешних CDN и сервисов, конфиг не покидает вашу сеть.

## Политика на каждого пира

Самое вкусное - каждому пиру назначается маршрутизация, как локальным устройствам:

* **Напрямую** - интернет через домашний IP (а дома, например, работает xray - тогда трафик пира автоматически поедет через него)
* **VPN: весь трафик** - **двойной хоп**: телефон → дом → внешний VPN-туннель роутера
* **VPN: гео-политика** - через внешний туннель только выбранные списки (YouTube и т.п.), остальное с домашнего IP

Плюс переключатель «что в туннель»: весь трафик телефона или только домашняя сеть (split-tunnel - батарейку бережёт). «NAT в LAN» включён по умолчанию - чтобы Windows-машины отвечали пиру, а не молчали из-за фаервола на «чужую подсеть».

## CLI, если лень открывать админку

```sh
/opt/etc/init.d/S99amneziawg server start
/opt/etc/init.d/S99amneziawg server stop
/opt/etc/init.d/S99amneziawg server diag
```
